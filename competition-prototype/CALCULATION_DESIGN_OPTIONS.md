# 竞赛版计算方向候选（先确认路线，再做最终 HTML/后端）

当前大创版的三项计算已经很明确：

1. 稳态水力分析：给定流量、管道和泵组，计算雷诺数、摩阻、压头和末站压力。
2. 敏感性分析：对几个输入做单因素 ± 百分比扰动，按摩阻变化计算敏感系数。
3. 泵站优化：枚举固定的 ZMI480/ZMI375 泵数组合，以可行和末站压力/费用规则选方案。

如果只是换图表、换颜色、把单因素改成多因素，评委仍然能看出它们属于同一套“稳态水力 + 局部扰动 + 泵组选优”计算。因此建议把竞赛版的三个页面改成下面三个真正不同的石油管道计算模块。

## 推荐路线（推荐采用）

### A. 瞬态压力波与水击风险分析（替代原“水利分析”）

石油液体管道的瞬态过程可以用特征线法求解。经典油管瞬态研究已经将水击方程和特征线法用于油管系统，并与现场试验进行比较；近年的液体管道研究也继续使用特征线法处理压力波传播和边界变化。

核心方程（建议在正式后端中实现）：

```text
∂H/∂t + a²/(gA) · ∂Q/∂x = 0
∂Q/∂t + gA · ∂H/∂x + f·Q|Q|/(2DA) = 0
C⁺: H − (a/gA)Q = constant − friction term
C⁻: H + (a/gA)Q = constant − friction term
```

输入：基准流量、阀门关闭时间、泵启停时间、波速 `a`、管径、长度、粗糙度、密度、弹性模量、首末端边界压力、最大允许压力。

输出：沿程压力波动画、任意位置压力—时间曲线、最大/最小压力、超压持续时间、负压风险、危险位置和推荐阀门关闭时间。

与大创版的差异：

- 状态从“一个稳态结果”变成“空间—时间压力场”；
- 输入新增阀门/泵启停事件和波速、弹性参数；
- 输出从单个末站压头变成压力波传播、峰值、持续时间和风险等级；
- 计算方法从代数摩阻计算变成偏微分方程离散/特征线推进。

### B. 计算管道监测与负压波泄漏定位（替代原“敏感性分析”）

API RP 1130 将 Computational Pipeline Monitoring（CPM）定义为识别可能泄漏的液体管道液压异常的算法工具；API RP 1175 则强调通过分层检测和快速响应降低事故后果。负压波方法以泄漏产生的压力稀疏波到达上、下游传感器的时间差定位泄漏，已有油管研究将小波处理和 GPS 时间同步用于提高定位精度。

核心计算（简化原型）：

```text
Δt = t_down − t_up
x_leak = (L − a·Δt) / 2
Δp = p_baseline − p_measured
Q_leak = C_d · A_leak · √(2Δp/ρ)
AlarmScore = w₁·|Δp|/σ_p + w₂·|ΔQ|/σ_Q + w₃·waveletCorrelation
```

输入：首站/末站压力与流量时间序列、传感器位置、采样频率、波速、基线窗口、报警阈值、孔口流量系数。

输出：是否疑似泄漏、泄漏发生时间、距首站位置、估算泄漏量、置信度、上下游证据波形、误报原因。

与大创版的差异：

- 不再扰动管径/粗糙度后看摩阻变化；
- 输入变成传感器时序和异常事件；
- 输出变成“检测—定位—估计—置信度”的安全监测链路；
- 计算核心从参数敏感度变成信号检测、时间差定位和异常评分。

### C. 多油品顺序输送排产与混油界面预测（替代原“泵站优化”）

多产品管道研究常用 MILP/MINLP 描述油品批次、注入顺序、输送时间、库存、交付量和混油界面。文献中已有连续时间 MILP、液压约束调度和库存联动模型；这比“枚举几组泵”更像石油管道领域的运营决策问题。

决策变量：

```text
y[p,k,t] ∈ {0,1}       第 t 个时段是否注入产品 p 的第 k 批
q[p,t] ≥ 0             产品 p 在时段 t 的注入量
I[p,t] ≥ 0             站场/油库产品库存
z[p,q,t] ∈ {0,1}       相邻批次是否发生产品切换
```

目标函数：

```text
min J = c₁·泵送能耗 + c₂·混油处理成本 + c₃·延期/欠交惩罚
      + c₄·库存占用成本 + c₅·切换/启停成本
```

约束：库存平衡、需求满足、批次连续性、管道容量、泵和流量上下限、禁止相邻油品序列、交付时间窗。

混油界面可在原型阶段采用轴向弥散模型：

```text
∂c/∂t + v·∂c/∂x = D_ax·∂²c/∂x²
```

输入：油品列表及密度/粘度、批次体积、需求和交付时窗、油库容量、管道长度/截面、允许流量、泵能耗参数、切换规则。

输出：油品顺序甘特图、注入/到站时间、每种油品交付量、混油界面长度/体积、能耗成本、欠交风险和可替代排产方案。

与大创版的差异：

- 不再把“泵的台数”作为唯一核心决策；
- 决策对象变成油品批次、顺序、时间和库存；
- 目标从“找一组泵”变成成本、混油、库存和交付的组合优化；
- 页面可以直接呈现油品时间轴、站场库存和界面移动，视觉表达比单个柱状图更适合数字媒体竞赛。

## 可选备选路线（如果项目有蜡油/温度数据）

### D. 含蜡原油沉积与停输再启动安全

含蜡原油页面可以计算环境温度、油温、蜡出现温度（WAT）、蜡层厚度、有效内径、压降和安全再启动时长。公开研究将蜡沉积、停输降温和再启动压力联立建模，并指出蜡层会改变有效直径与再启动安全边界。

这条路线的视觉效果很强，但必须有 WAT、环境温度、蜡含量/沉积参数、保温结构和停输时长，否则只能做演示模型，不能冒充现场结果。

## 我建议你选择

首选 **A+B+C**：

- 页面 1：瞬态压力波与水击风险；
- 页面 2：CPM/负压波泄漏检测定位；
- 页面 3：多油品顺序输送排产与混油界面预测。

这个组合比原项目至少改变了四个可审查维度：物理状态、输入数据、决策变量、评价指标。它不是“同一个计算换皮”，而是从稳态水力计算转向安全监测、瞬态控制和石油物流调度。

# 管道摩阻损失过大处置规程（G-E3）

故障现象：全线摩阻损失显著增大，泵站出口压力被顶高，输送流量下降，能耗分析显示单位输量能耗超基准 15%。

原因诊断（按雷诺数分算）：
1. 摩阻损失偏大——管道结蜡使等效粗糙度增大，水力坡降随之抬升；
2. 雷诺数从高湍流区滑向过渡区时摩阻系数陡增，常因流量长期偏低（降负荷输送）；
3. 油温偏低导致黏度升高，摩擦项与黏度项同时恶化。

处置方案：
1. 提高输送温度（掺热/加热炉提温 5-8℃），降低原油黏度；
2. 恢复正常输量，使雷诺数回到完全湍流区，压低摩阻系数；
3. 安排热油清蜡作业（水力清管器 + 热油循环），恢复管径通畅；
4. 按 8 泵组合迭代寻优，选择末站压力可行且能耗最低的泵组配置。

预防措施：水力计算按季更新粗糙度参数；摩阻损失超 10% 基准即触发清蜡计划。

关联概念：摩阻损失、水力坡降、雷诺数、降负荷、结蜡、泵组优化。

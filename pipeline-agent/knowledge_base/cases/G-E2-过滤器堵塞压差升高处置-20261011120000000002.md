# 管道入口过滤器堵塞处置规程（G-E2）

故障现象：泵站入口过滤器压差持续升高，超过报警阈值（0.12 MPa），泵进口负压增大，出现气蚀前兆。

原因诊断：
1. 过滤器堵塞——长期未切换清洗，滤网截留蜡晶、水分离物与泥沙；
2. 原油黏度季节性升高（冬季），蜡晶析出加剧堵塞速率；
3. 过滤器网面破损导致局部短路，压差读数失真。

处置方案：
1. 切换至备用过滤器，故障过滤器退出流程；
2. 清洗滤网：热油冲洗（50-60℃）+ 高压水射流，检查网面破损并补焊；
3. 冬季投运前对过滤器加装伴热保温，降低蜡晶沉积；
4. 恢复后跟踪压差 24h，回落至 0.03 MPa 以内判定恢复；
5. 同步检查上游分油器，防止水相混入。

预防措施：建立过滤器切换周期台账（正常 72h 一班）；压差 0.08 MPa 黄色预警、0.12 MPa 强制切换。

关联概念：过滤器堵塞、压差升高、切换清洗、蜡晶、气蚀。

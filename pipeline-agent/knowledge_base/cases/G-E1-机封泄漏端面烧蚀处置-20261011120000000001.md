# 离心泵机械密封泄漏处置规程（G-E1）

故障现象：离心泵机械密封（机封）持续泄漏，端面出现烧蚀发亮痕迹，泵腔温度偏高。

原因诊断：
1. 端面烧蚀——密封副摩擦热积累，冷却冲洗液不足或中断，导致端面干摩擦；
2. 冲洗液介质温度高、黏度低，端面润滑膜被破坏；
3. 泵在低流量区长时间运行，轴向推力不平衡顶紧密封副。

处置方案：
1. 立即切换备用泵，隔离故障泵；
2. 恢复冲洗液通路（检查冲洗线过滤器、冲洗泵），降低端面温度；
3. 端面轻度烧蚀：停机后用 800 目以上细砂纸研磨端面，恢复平面度后试压；
4. 端面深度烧蚀/裂纹：整体更换密封副（动环+静环），同步更换 O 形圈；
5. 启动后 30 分钟内巡检机封温升，稳定在 60℃ 以内判定合格。

预防措施：冲洗系统加装压差报警；低流量区加最小回流线；机封寿命周期 8000h 强制更换。

关联概念：机封泄漏、端面烧蚀、研磨恢复、冲洗液、叶轮磨损。

# 客户现场：管线输送异常处置知识库

某输油管道投产三年现场积累。以下为高频故障的因果链与处置经验，
按"故障 → 原因 → 处置"整理，并标注该条目在客户现场的重要程度
（核心故障/高频原因给高分）。

## 故障一：末站进站温度偏低

- 现象：末站进站油温比设计低 4~6℃，影响后续加热站负荷。
- 主要原因：管道保温层局部破损（重要度 0.9）；伴热功率不足（0.7）；
  输送流量短时拉高（0.5）。
- 处置：巡检定位破损保温段并补做保温（高优先）；核算伴热实际功率并
  加配电容（中）；按季节曲线控量输送（低）。

## 故障二：输油泵电流突增

- 现象：某机组电流短时突增 15%~30%，触发过载保护。
- 主要原因：泵入口过滤器压差过大（0.95，几乎每次的根因）；介质粘度季节性
  升高（0.6）；泵叶轮轻微磨损（0.3）。
- 处置：在线清洗/更换入口过滤器滤网（核心，必做）；按油温调整粘度后
  重新核定扬程（中）；安排停机做叶轮探伤（低，周期长）。

## 故障三：管道局部摩阻异常升高

- 现象：某管段摩阻较基线上浮 8% 以上。
- 主要原因：管壁结蜡（0.8，冬季高发）；介质含水率上升（0.5）；
  管道内浮生物（0.2）。
- 处置：投加降凝剂+热油循环（高优先）；脱水控制含水率（中）；
  评估清管作业（低，需停机窗口）。

## 通用原则

任何故障处置都应记录：发生时刻、当时流量/温度/粘度三参数、处置动作、
恢复时长。形成闭环后纳入本文档，供下次同类故障快速对照。

# 冬季输油风险处置知识

某管道冬季（11月~次年2月）运行风险经验，按故障因果整理：

## 故障：管道内结蜡导致摩阻升高

主要原因：油温偏低蜡晶析出（重要度 0.9）；流速低于临界携蜡流速（0.6）；
管壁粗糙度冬季加剧（0.3）。
处置：提高输送温度并投加降凝剂（高优先）；核算季节性流速下限并控量（中）；
安排冬季专项清管（低，需停机窗口）。

## 故障：伴热电缆故障导致管段失热

主要原因：伴热电缆老化短路（0.8）；伴热控制器温控漂移（0.5）；
积雪覆盖伴热管段散热加剧（0.4）。
处置：巡检伴热回路绝缘并更换老化段（高优先）；标定伴热控制器温控（中）；
除雪并加设伴热段保温罩（低）。

# 泵站出口压力持续下降根因处置规程（G-E4）

故障现象：泵站出口压力在数小时内持续下降（非瞬时波动），流量基本不变，末端站进站压力随之走低。

原因诊断（因果链）：
1. 叶轮磨损——长期磨蚀使叶轮出口流道变大、容积损失增加，同转速下扬程下降；
2. 管路/过滤器结蜡——等效阻力增大，泵特性曲线右移但流量被顶低；
3. 油品变稀（密度下降）——同扬程下压力头转化降低；
4. 泵转速波动——变频给定漂移或电源闪变导致实际转速低于额定。

处置方案：
1. 对比历史曲线判定是缓变（磨损/结蜡）还是突变（转速/汽蚀）；
2. 缓变类：安排叶轮检修或更换，同步清蜡恢复管径；
3. 突变类：检查变频器输出与电网，复位转速给定；核查泵入口液位防汽蚀；
4. 过渡期通过提温增黏或降负荷输送稳住末站压力；
5. 恢复后跟踪 72h 出口压力曲线。

预防措施：叶轮磨蚀监测（振动+间隙测量）纳入周期检修；出口压力下降率 0.02 MPa/h 触发根因诊断流程。

关联概念：泵站出口压力下降、叶轮磨损、更换叶轮、过滤器堵塞、雷诺数。

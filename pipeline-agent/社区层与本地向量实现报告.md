# 报告二：图社区层（GraphRAG 2.0）+ 本地向量模型 工程实现

- 日期：2026-10-11
- 范围：pipeline-agent（feature/rag-graph-llm-techdebt）
- 目标：把"单纯图 RAG"升级成"图结构 + 摘要语义"双能力；向量检索切到本地小模型，
  离线无 key 可跑、评测 dense/hybrid 走真向量。

## 一、本地向量模型（dense 检索真向量）

**为什么**：原 dense 走远端 API（DashScope 1024 维），本环境 LLM/向量 key 都不可用
（GLM 无额度、AGNES 端点不可达）→ dense 一直降级为空。

**怎么做**：
- 新增 `EMBEDDING_BACKEND=local` + 本地小模型
  `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`（384 维、多语言、CPU）。
- `embeddings.py`：`_LocalSentenceEmbeddings` 懒加载 `SentenceTransformer(cpu)`，
  按 backend 二选一（api 路径不变，可一键切回）。
- `vector_store.py` + `pipeline.py`：维度自适配，切维度自动 drop 重建 collection。
- 实测：25 文档 / 248 分块以本地 384 维向量入库 Milvus；语义区分正确
  （"泵站出口压力下降" ≈ "持续下降" cos 0.939）。

**收益**：评测 dense 不再降级（MRR 0.767），hybrid/hybrid_graph 拿到真向量腿。

## 二、图社区层（GraphRAG 2.0）

**为什么**：现状图检索只有"离散步搜 + 子图概念回查 BM25"一条腿，子图摘要没向量，
跨概念语义聚合断了 → 评测 graphrag MRR 仅 0.144。

**怎么做（纯算法、无 LLM、可复现可单测）**：
1. **社区发现** `community.build_communities`：图弱连通分量切社区；
   分量 >50 节点时退化为按 NodeType 大类（fault/equipment/standard/document）切分。
2. **规则摘要** `_summarize_community`：实体名按 NodeType 分组 + 因果链
   fault→cause→solution 串起来 + top-k 度数概念。
3. **摘要向量化** `upsert_community_vectors`：摘要过本地 embedding（384 维）→
   写 Milvus 独立 collection `pipeline_knowledge_communities` + 落盘
   `knowledge_base/.registry/communities.json`（含向量、revision）。
4. **检索粗筛** `community_search`：query 向量 vs 摘要向量 COSINE 粗筛 top-k 社区，
   命中社区带回 source_docs/chunk_ids；开关关 / 无社区 / 失败 → no-op 不阻断。

**接入点**：
- `graph_rag.py` 的 `retrieve`：命中社区时把摘要拼进结果（单路追加，**不做多路 RRF
  融合**——按用户要求保持单路语义）。
- `pipeline.py` 的 `index_documents_report` 尾部自动建社区索引（失败降级跳过）。
- 门控 `RAG_GRAPH_COMMUNITY`（默认开）。

**实测**：4 社区建好并向量化入库；`community_search("泵站出口压力下降 处置")`
命中 fault 因果社区 c0001（score 0.491，排序语义正确）。

## 四、验证

- pytest **100 全绿**（含 7 个社区单测、13 个 ENRICH 单测，无回归）。
- 端到端：本地向量入库 Milvus + 社区摘要向量化 + community_search 命中全部跑通。
- 降级验证：`RAG_GRAPH_COMMUNITY=false` / `EMBEDDING_BACKEND=api` 可一键切回，行为不变。

## 五、遗留

1. 专家数据节点没带 doc_id → 社区 `source_docs` 多为空（数据现状，distill 上来后填）。
2. 摘要用规则拼接（无 LLM）——可换 LLM 摘要生成器（社区结构不变，只换摘要来源）。
3. 本轮改动未 commit；Milvus 两个 384 维 collection + communities.json 是运行时产物。
4. 评测脚本保持单路（未做多路融合）；若要量化社区腿在评测里的分数，
   可单独给 graphrag 模式加 community 召回展示（不融合），待确认。
